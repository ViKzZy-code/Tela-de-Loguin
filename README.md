# 🔐 Tela de Login

Uma tela de login desenvolvida com **HTML**, **CSS** e **JavaScript**, criada com o objetivo de praticar a construção de interfaces web, estilização de componentes e interação com o usuário. O projeto apresenta uma interface simples e moderna para autenticação, explorando conceitos fundamentais do desenvolvimento front-end.

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript (ES6)

## Funcionalidades

* Interface de login com campos para usuário e senha.
* Validação básica dos campos utilizando JavaScript.
* Interações com o usuário através de eventos.
* Estilização personalizada para melhorar a experiência visual.
* Estrutura organizada para facilitar futuras melhorias.

Este projeto foi desenvolvido como prática dos conceitos iniciais de desenvolvimento web, permitindo aprimorar conhecimentos em criação de layouts, manipulação do DOM, eventos e lógica de programação com JavaScript. É um projeto simples, mas representa uma etapa importante no aprendizado e evolução na área de desenvolvimento front-end.
